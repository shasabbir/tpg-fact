# Revised Phase-2 manuscript

This manuscript reports the completed retrieval-conditioned Phase-2 study. It is
separate from the frozen Phase-1 paper in `paper/`.

The tables and figures are generated from audited outputs by:

```powershell
cd experiments
.\.venv-workstation\Scripts\python.exe scripts\build_q1_phase2_reporting.py
```

Compile `paper.tex` from this directory. The output PDF is copied to the stable
release location after render-and-visual verification.
