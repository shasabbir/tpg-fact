# DTP-Fact feasibility pilot

Private research bundle containing 200 image--text ClaimReview cases, 682 time-valid evidence records, image hashes, frozen temporal splits, and audit ledgers.

The pilot evidence gate passed (200/200 claims have evidence; 141/200 have two source-domain clusters). The source-domain clusters are a pilot proxy pending the final source-dependency graph audit. This is not the final 2,000-case benchmark and it does not validate final paper results. Keep the Kaggle Dataset private.
