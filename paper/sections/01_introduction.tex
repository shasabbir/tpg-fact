\section{Introduction}
\label{sec:introduction}

Only an evidence-based verdict is auditable, and then only if the reader can view the material underlying the verdict. In the multimodal context that might be sentences, documents and images. While modern systems can draw a huge list of candidates, the fact-checker still requires a concise list of candidates that is relevant enough to examine and substantive enough for a decision. MOCHEG explicitly states the problem with image-text claims, text evidence, image evidence, and three-way verdicts \cite{yao2023mocheg}.

The final evidence is most commonly selected by a fixed top-$k$ rule that most pipelines use. This is very easy to replicate, but assumes that each claim requires the same number of items. Adaptive selectors, however, select a claim-specific set on the basis of membership scores. A threshold returns all candidate items with a score above a cutoff. A count model predicts the set size. Expected-F1 decoding finds the candidate prefix with the highest expected set F1. All these rules have a common dependency: their scores must behave like probabilities. Ranking quality alone is not enough. A monotone score transformation does not affect the ranking, but does change the threshold and expected-F1 decisions.

Such a dependency is particularly dangerous when classes are imbalanced. Membership of evidence is uncommon in a retrieved packet and balanced logistic training makes a deliberate change to the effective class prior. Temperature scaling can change confidence but cannot correct an intercept error caused by the prior. When this mismatch is not taken care of, an expected-utility decoder could over-pick candidates despite the increase of average precision.

Retrieval creates a second dependency. A selector can't get an item that's not in its packet. If the packet oracle is not included, a decoding error and a retrieval miss can look identical in the reported selector F1. Thus, we consider selection within one pipeline (and one only), as illustrated in Fig.~\ref{fig:architecture}. All methods are given the same 40 text and 20 image candidates, and the same complete-gold mapping, which was released.

The study has four questions:
\begin{enumerate}
    \item What is the amount of released gold evidence that can be retrieved at the real packet depths?
    \item What are the probability maps that correct the calibration error due to imbalance?
    \item Is there an advantage to calibrated expected-F1 selection over a fixed top-$k$ selection and a calibrated threshold?
    \item Are evidence-set gains maintained across probability, modality, packet-width and retrieval perturbations, and do they maintain verdict quality under a shared verifier?
\end{enumerate}

Isotonic, Platt and prior-shift maps all produce a dramatic decrease in the Brier error. With prior-aware calibration, expected-F1 returns 3.50 items on average with an improvement of $0.0085$ evidence F1 compared to fixed top-5. The fitted size and redundancy penalties are zero for all the deterministic partitions, and thus do not affect the output. The calibrated threshold does better, improving on fixed top-5 by $0.0133$. The two adaptive rules are still limited to a packet oracle of 0.3560 F1.

This paper makes four contributions:
\begin{itemize}
    \item retrieval-conditioned evaluation which provides information on operating-depth recall, packet-oracle F1, complete-gold coverage and unreachable claims;
    \item a controlled comparison of six calibration maps for balanced (and unweighted) multimodal membership scorers;
    \item a claim-aligned comparison of fixed, threshold, count, and expected-F1 selection with a reachability-stratified error analysis, a shared-verifier safeguard, and controlled perturbations;
    \item an auditable implementation with frozen data revisions, saved candidate probabilities, independent recomputation of metrics and a clean deterministic rerun.
\end{itemize}

It is possible to create a better expected-F1 selection than having a fixed evidence budget, provided that the inputs to the selection are set appropriately to the deployment prior. Calibrated thresholding works better in these experiments and the expected-F1 gain is eliminated when there is little probability distortion. Experimental variables of calibration and reachability should accordingly be reported as part of evaluations of adaptive evidence selection.
