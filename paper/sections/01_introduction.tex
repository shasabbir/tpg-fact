\section{Introduction}
\label{sec:introduction}

A fact-check is auditable only when a reader can inspect the material behind
its verdict. For an image--text claim, that material can include sentences,
documents, and images drawn from different sources. A retrieval system may
return hundreds of plausible candidates, but a reviewer still needs a short
set that contains enough support or refutation to make a decision. MOCHEG
formalizes this setting with multimodal claims, separate text and image
evidence, released evidence identifiers, and three-way verdicts
\cite{yao2023mocheg}.

Evidence selection is often reduced to a fixed top-$k$ rule. It is simple and
reproducible, but it assumes that every claim needs the same number of items.
Adaptive policies instead map candidate-level membership scores to a
claim-specific set. A threshold returns every item above a cutoff, a count
model predicts the set size, and expected-F1 decoding chooses the probability-
ranked prefix with the greatest expected set F1. These rules share a dependency
that rank-only evaluation can hide: the scores must behave like probabilities.
A monotone transformation preserves candidate order while changing threshold
and expected-utility decisions.

Class imbalance makes this dependency consequential. Gold evidence is rare in
a retrieved packet, while balanced logistic training deliberately changes the
effective class prior. A temperature map can adjust confidence without fixing
an intercept error produced by that prior mismatch. Modern calibration work
therefore distinguishes ranking, probability quality, and the decision made
from those probabilities \cite{silvafilho2023calibration}. In an evidence
pipeline, an apparently stronger adaptive decoder may otherwise be exploiting
or amplifying a calibration error.

Retrieval creates a separate, harder boundary. A selector cannot return an
item that never enters its packet. If packet reachability is not reported, a
retrieval miss and a decoding error receive the same final evidence score.
Figure~\ref{fig:architecture} shows the information boundaries used here. All
selection policies receive the same 40 text and 20 image candidates. Candidate
rankings are written before the gold join; scoring, calibration, policy
selection, and evaluation use disjoint roles; and the released validation set
is evaluated only after train-role choices are fixed.

The study asks four questions:
\begin{enumerate}
    \item How much released gold evidence is reachable at the actual packet
    depths, and can a bounded label-blind rank fusion improve that ceiling?
    \item Which probability maps correct the prior error induced by imbalanced
    evidence membership?
    \item How do fixed top-$k$, calibrated thresholding, learned count,
    expected-F1, and an uncalibrated ablation compare on identical packets?
    \item Does a prespecified packet-completeness switch beat calibrated
    thresholding and preserve verdict quality under a stronger shared verifier?
\end{enumerate}

The answers are deliberately mixed. Weighted text fusion improves the
all-eligible packet oracle from 0.3560 to 0.3637 F1 and complete-gold coverage
from 4.39\% to 4.74\%, while image Recall@20 does not change. Prior-aware maps
repair the dominant probability error. On the repaired packet, calibrated
thresholding reaches 0.1864 evidence F1, expected-F1 reaches 0.1815 with a
smaller 3.61-item set, and uncalibrated expected-F1 collapses to 0.1288 while
returning 24.90 items. The completeness-aware switch has the highest point
estimate, 0.1877 F1, but improves over thresholding by only 0.00138 with an
interval that crosses zero. Its verifier result passes aggregate
non-inferiority but not the per-seed safeguard.

This paper makes four contributions:
\begin{itemize}
    \item a retrieval-conditioned evaluation that reports operating-depth
    recall, packet-oracle F1, complete-gold coverage, and zero-reachable claims
    before interpreting selector quality;
    \item a matched calibration and set-decoding study covering six probability
    maps, fixed and adaptive controls, exact expected-F1, and an uncalibrated
    failure case;
    \item a prespecified retrieval repair and packet-completeness-aware switch,
    evaluated against the strongest calibrated-threshold comparator with
    claim-aligned intervals and partition-level safeguards; and
    \item an auditable implementation that preserves label-blind rankings,
    failed runs, per-claim records, configuration and environment hashes, and
    independent output audits while keeping the formal test sealed.
\end{itemize}

The contribution is empirical rather than a claim of state-of-the-art
performance. Adaptive evidence sizing is useful only after retrieval and
calibration are exposed as experimental variables. In this study,
expected-F1 supplies a precision-oriented operating point and the
completeness-aware switch supplies a testable design direction, but calibrated
thresholding remains the strongest confirmed policy. The paper retains that
negative boundary because it changes how future selector improvements should
be evaluated.
