\section{Limitations and Ethics}
\label{sec:limitations}

\subsection{Limitations}

MOCHEG validation informed earlier project development, and the original complete-reachability subgroup was identified post hoc. The separately frozen AVerImaTeC comparison uses development claims and a store partly acquired using annotated questions. Exact matching can miss equivalent passages or images. Full semantic scoring and human adjudication remain open. The ranked pool has zero exact-positive image candidates, the policies select only text, and the split has one Conflicting claim. Consequently, external findings about visual evidence selection and rare verdicts are limited. The small scorer, completeness model, and verifier bound the model comparison. Expected-F1 assumes conditionally independent memberships and searches ranked prefixes, although items can be redundant or complementary. Robustness perturbations measure sensitivity under controlled interventions. Set size is a proxy for review effort. Both formal test sets remain sealed.

\subsection{Ethical Considerations}

An empty annotated overlap can arise from retrieval failure, incomplete annotations, or equivalent evidence with a different identity. Automated fact-checking interfaces should expose retrieved sources and their limits so users can inspect the basis of a verdict. Web evidence can contain personal, copyrighted, or disturbing material. Reuse should follow the source terms and limit unnecessary reproduction. The benchmark populations bound the languages, communities, and media settings where the findings have been examined.
