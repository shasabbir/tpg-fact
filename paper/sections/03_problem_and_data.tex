\section{Problem Formulation and Datasets}
\label{sec:data}

Let a claim be $c$, its candidate evidence packet be $E=\{e_1,\ldots,e_n\}$, and its verdict be $y$. Each item has an immutable identifier and a modality in \{text, table, figure, image, caption\}. The system predicts a verdict distribution $p(y\mid c,E)$, an ordered citation set $S\subseteq E$, and an explanation $r$ whose factual sentences cite one or more elements of $S$.

Evidence attribution is evaluated against dataset-provided evidence identifiers. For datasets with multiple valid evidence sets, a citation is correct when it belongs to any admissible set. A model is evidence-traceable only when its cited set is accurate and its prediction behaves appropriately when that evidence is changed.

\subsection{Public Datasets}

Table~\ref{tab:datasets} lists the planned datasets. SciVer is the primary benchmark because it supplies expert evidence and rationales under a CC BY 4.0 release \cite{wang2025sciver}. MuSciClaims provides an external scientific test \cite{wang2025musciclaims}. MOCHEG supplies general-domain transfer and direct comparability with the base papers \cite{yao2023mocheg}. AIChartClaim is optional and enters the main study only if its use terms and split audit pass.

No new web corpus is collected. Official splits are retained unless leakage auditing requires a grouped split; any replacement split is released as an identifier manifest rather than by redistributing source media.

\subsection{Dataset Audit}

Before training, each release is checked for access terms, missing modalities, exact hashes, perceptual image duplicates, claim overlap, label balance, evidence-ID integrity, and leakage through paths or metadata. A dataset is excluded from primary tables if fewer than 90\% of selected examples retain the modalities required by its task or if unresolved leakage makes the endpoint uninterpretable.
