\subsection{Reproducibility Record}

A repository README specifies the name of the frozen configuration, result directories and reporting bundle. The clean rerun is put into another output directory. All 20 core selector and verifier artifacts match byte-for-byte by SHA-256. Independent metric audits are done for runtime-bearing summaries, which are not included in the byte comparison.

There are exactly 1,490 locked-validation claim records in each of the five selector partitions for each method. The scorer output, calibrated probability, rank, modality, gold membership and selected-set decisions are stored in candidate records. Selector, verifier, robustness, audit and reporting records contain formal-test access flags that are false.

\subsection{External Evaluation Path}
\label{sec:external}

AVerImaTeC now offers an evaluated test setting as well as a public task report \cite{cao2026averimatecshared}. A useful transfer study would map its question-answer evidence to a stable selectable unit, fit calibration only on its released training resources, and report the official conditional evidence-verdict score as well as set size and reliability. A multi-hop set objective would be necessary, with a three-modality scorer, for MMCV. MOCHEG calibration parameters should not be reused in either transfer.
