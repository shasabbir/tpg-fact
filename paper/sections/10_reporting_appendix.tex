\subsection{Reproducibility Record}

A repository README specifies the frozen configurations, result directories,
and reporting bundles. The earlier diagnostic clean rerun places outputs in a
separate directory; all 20 core selector and verifier artifacts match
byte-for-byte by SHA-256. The bounded repair adds source hashes for retrieval,
selector, completeness, and verifier summaries and independent audits for each
stage. Runtime-bearing summaries are independently recomputed rather than
expected to match byte-for-byte.

There are exactly 1,490 locked-validation claim records in each of the five
selector partitions for each method. The repaired candidate bundle contains
789,540 rows for 13,159 released train and validation claims before the
complete-gold eligibility filter. Candidate records store scorer output,
calibrated probability, rank, modality, gold membership, and selected-set
decisions. Selector, completeness, verifier, audit, and reporting records all
contain false formal-test access flags.

\subsection{External Evaluation Path}
\label{sec:external}

AVerImaTeC offers an evaluated test setting and a public task report
\cite{cao2026averimatecshared}. A useful transfer study would map its
question--answer evidence to a stable selectable unit, fit calibration only on
released training resources, and report the official conditional
evidence--verdict score together with set size and reliability. A separate
three-modality study would need a hash-locked split, table representation, and
multi-hop set objective. MOCHEG calibration parameters should not be reused in
either transfer.
