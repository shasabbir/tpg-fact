\subsection{Reproducibility Record}

A repository README specifies the frozen configurations, result directories,
and reporting bundles. The earlier diagnostic clean rerun places outputs in a
separate directory; all 20 core selector and verifier artifacts match
byte-for-byte by SHA-256. The bounded repair adds source hashes for retrieval,
selector, completeness, and verifier summaries and independent audits for each
stage. Runtime-bearing summaries are independently recomputed rather than
expected to match byte-for-byte.

There are exactly 1,490 locked-validation claim records in each of the five
selector partitions for each method. The repaired candidate bundle contains
789,540 rows for 13,159 released train and validation claims before the
complete-gold eligibility filter. Candidate records store scorer output,
calibrated probability, rank, modality, gold membership, and selected-set
decisions. Selector, completeness, verifier, audit, and reporting records all
contain false formal-test access flags.

\subsection{External Evaluation Path}
\label{sec:external}

AVerImaTeC offers an evaluated test setting and a public task report
\cite{cao2026averimatecshared}. We froze a transfer protocol that maps each
store URL and a claim-matched, 1,500-character chunk to a deterministic
candidate identifier. It fits every scorer and calibrator from scratch on the
793 released training claims, reserves the 152 development claims for one
locked comparison, caps outputs at ten items, and does not transfer MOCHEG
parameters. Gold questions are excluded from retrieval features, and exact
source membership is joined only after label-blind rankings are written and
hashed.

An access audit used a public participant-released filled validation store to
validate this adapter without treating it as the prespecified experiment. It
produced 129,475 candidates, or 851.8 per claim.
The full pool reaches 92.94\% of normalized annotated sources and contains the
complete annotated source set for 84.21\% of claims. Claim-text ranking is much
weaker: exact-source Recall@10, @20, @50, and @100 is 4.82\%, 8.00\%, 13.21\%,
and 19.48\%. This gap confirms that candidate availability does not imply
shallow retrieval success. These values are diagnostics for a participant-
filled store, not the official semantic evidence score or a selector result.

We do not claim independent confirmation at manuscript cutoff. The complete
organizer training text store was not locally available after the public host
enforced its download quota, and the prescribed Gemma-3-27B judge has 54.86~GB
of weight files versus 25.76~GB of local GPU memory. We neither substituted the
filled validation store for training nor reported a quantized replacement
judge as official. The blind test and leaderboard remain untouched. A separate
three-modality study would still require a hash-locked split, table
representation, and multi-hop set objective.
