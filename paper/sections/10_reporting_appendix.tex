\subsection{Reproducibility Record}

The frozen configuration, result directories, and reporting bundle are named in the repository README. The clean rerun uses a separate output directory. All 20 core selector and verifier artifacts match byte-for-byte by SHA-256. Runtime-bearing summaries are excluded from the byte comparison and are checked by independent metric audits instead.

All five selector partitions contain exactly 1,490 locked-validation claim records for each method. Candidate records preserve the scorer output, calibrated probability, rank, modality, gold membership, and selected-set decisions. Formal-test access flags are false in selector, verifier, robustness, audit, and reporting records.

\subsection{External Evaluation Path}
\label{sec:external}

AVerImaTeC now provides an evaluated test setting and a public task report \cite{cao2026averimatecshared}. A useful transfer study would map its question-answer evidence into stable selectable units, fit calibration only on its released training resources, and report the official conditional evidence-verdict score alongside set size and reliability. MMCV would require a three-modality scorer and a multi-hop set objective. Neither transfer should reuse MOCHEG calibration parameters.
