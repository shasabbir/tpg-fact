\section{Discussion}

The central question has a negative answer: predicting evidence-set cardinality more accurately does not necessarily improve citation macro-F1. \method{} lowers count error and raises exact count match, yet fixed top-two returns the stronger evidence set. Because verdict vectors and rankings are identical across these outputs, the result cannot be attributed to a different verifier, representation, or candidate order. It isolates citation-set size as the cause.

Two mechanisms explain the failure. First, count cross-entropy rewards agreement with the annotated set length, whereas citation F1 rewards overlap after ranking errors. If a gold item falls below rank $k$, predicting the correct $k$ can still miss it; returning one extra item can improve recall enough to offset lower precision. The gold-cardinality diagnostic confirms this mismatch because it also trails fixed top-two. Second, the cardinality head is unstable across seeds. Its output is nearly fixed at one item for two seeds and approaches two for others. This variation survives despite fixed data and features, indicating that the small development partition does not identify a stable count rule.

The ablations narrow the design lesson further. The valid-candidate count is harmful under the frozen test, while the visual-count effect is unresolved. Packet-level availability statistics therefore should not be treated as generally useful cardinality signals. A better objective would need to account for ranking uncertainty and marginal citation utility rather than imitate count alone. Selective citation or abstention may also be preferable when no high-confidence prefix is available, but the consumed official test cannot be used to tune such a revision.

The controlled negative result is still informative. It shows why comparing an adaptive method only with an inherited top-three budget would have produced a misleading success claim: \method{} beats top-three but not the stronger top-two rule. Reporting all reasonable global budgets, preserving failed hypotheses, and enforcing verdict/ranking identity are therefore substantive evaluation requirements for citation-sizing research.
