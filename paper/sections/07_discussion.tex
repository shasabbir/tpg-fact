\section{Discussion}

The study tests a narrow mechanism: choosing the evidence prefix by expected set utility rather than by a global budget or a predicted count. The exact decoder is meaningful only if item probabilities are informative and sufficiently calibrated. A development gain would support advancing the mechanism, but it would not by itself establish end-to-end fact-checking quality because the feasibility packet begins from released judgment candidates and the verifier branch remains pending.

Several outcomes have prespecified interpretations. If \method{} improves evidence F1 but calibration does not improve Brier score, the calibration contribution must be removed or narrowed. If evidence selection improves while verdict macro-F1 violates the non-inferiority margin, the selector is not operationally successful under the stated task. If only one evidence-count or modality subgroup improves, the main claim must remain aggregate and the subgroup finding exploratory. If the strongest fixed budget wins, the project preserves that negative result and does not inspect the test in search of a favorable comparison.

The development gate is deliberately demanding because the formal benchmark can be consumed only once for a confirmatory interpretation. It also prevents a repetition of the preceding count-prediction study's main evaluation error: beating one convenient fixed budget while losing to another reasonable budget. The new protocol selects the comparator on permitted development data and requires a practically relevant effect across all pilot seeds before formal evaluation.

A positive MOCHEG result would still be bounded. It would show that expected-F1 decoding improves evidence selection under the released corpus, labels, and matched system, not that the method universally identifies truth or produces faithful natural-language explanations. A strong journal submission would benefit from a second licensed external benchmark after the MOCHEG protocol is frozen, but such an extension must not contaminate the main test.
