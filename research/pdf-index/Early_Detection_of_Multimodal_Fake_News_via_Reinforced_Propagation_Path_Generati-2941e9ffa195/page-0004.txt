B. Reinforced Propagation Paths Generation
After the user embedding is generated by dual-view con-
trastive learning, we target to simulate propagation process
with user embedding based on news content features. Since
users in propagation paths are represented in discrete spaces,
deﬁning a differentiable model as the generator directly becomes
challenging. Therefore, we employ the policy gradient approach
to optimize the generator and formulate the generation of prop-
agation paths as a reinforcement learning problem.
1) The Markov Decision Process: The user generation
within the reinforcement learning framework, is formulated as
a classic Markov Decision Process (MDP) represented by a 4-
tuple(S,A,Υ,Λ). Here,S signiﬁes the ﬁnite state space during
the exploration of user interaction, while A denotes the action
space for selecting the next user. The function Υ: S×A→R
serves as the reward function derived from the environment, used
to evaluate the quality of the generated propagation path. Ad-
ditionally,Λ: S×A→S represents the transition probability
function that determines the state transition based on the current
state and the selected action.
State: In the propagation simulation process, each statest ∈S
is denoted by a 4-tuple (n,Ut,Vt,Rt), where Ut signiﬁes the
newly selected users at step t. Vt and Rt represent the sets of
all users and connected edges up to step t, respectively. The
initial state is represented ass0 =( n,{un},{un},∅), whereun
denotes the seed node of the news item itself.
Action: The action space At for state st is deﬁned as the
collection of outgoing connections among users in Et, denoted
as At = {(r,e)|(uh,r,u ) ∈H ,uh ∈ Et,u/∈ Vt}.
Reward:The reward function assesses the quality of navigated
state. We deﬁne two rewards to provide feedback, the propa-
gation path temporal reward and the propagation path global
reward. Detailed elaboration can be found in Section III-B3.
