E. Parameter Sensitivity Analysis
Here we conduct hyper-parameter sensitivity analysis on
six parameters: the temperature parameter τ1 in node-view
contrastive learning, temperature parameter τ2 in meta-view
contrastive learning, the weighting coefﬁcient λ1 in contrastive
loss, the weighting coefﬁcient λ2 in reward loss, the top K1
sample nodes in contrastive learning and the max number out-
going relations K2 for one action in reinforcement learning. In
Fig. 4(a) and (b), with the increase of τ1, model performance
ﬁrst increases and then decreases. With a greater temperature
parameter the similarity distribution is smoother, which is beneﬁt
for model capturing the minor difference. While the common
feature may be ignored if the temperature parameter is too high.
In Fig. 4(c), with the increase of λ1, model performance ﬁrst
increases and then signiﬁcantly drops. A greaterλ1 leads to more
node view features with limited heterogeneous relation features,
while node view global structure is decreased if λ1 is too small.
In Fig. 4(d), with the increase of λ2, model performance im-
proves and then decreases. A greater λ2 leads to more temporal
reward in every action step, while global propagation reward is
introduced more if λ2 is too small. Fig. 4(e) shows that with the
increase of sample nodesK1, model performance ﬁrst improves
and then drops. This demonstrates that the reasonable number of
positive and negative node set are crucial for effective contrastive
learning. Fig. 4(f) shows that with the increase of the max num-
ber of outgoing relations K2, model performance ﬁrst improves
and then drops. This demonstrates that too much user interac-
tion in one step may hurt the quality of generated propagation
paths.
