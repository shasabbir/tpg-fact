3) Optimization of Propagation Path Generation: The prop-
agation generation process contains two types of rewards: Prop-
agation Path Temporal Reward and Global Reward.
Propagation Path Temporal Reward: In order to effectively
capture the temporal features of propagation, it is essential to
simulate each search action at time step t to align with the
propagation time slots. Consequently, the agent should prioritize
selecting users who are actively engaged at the current time step
along the real propagation path. To achieve this objective, we
divide the propagation temporal process evenly and construct a
temporal user engagement list to record all user actions at time
step t during the real propagation process. This list, denoted
as Ω(t)= {u1,u2,...,u k|ui acts at t}, serves as a repository
for user engagements at speciﬁc time steps. Mathematically, the
reward function is represented as:

Propagation Path Global Reward:The real propagation paths
